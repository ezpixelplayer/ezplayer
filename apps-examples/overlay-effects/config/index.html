Overlay Effects settings

Effects are painted onto the submodels of each chosen model, one overlay lease per submodel (or onto the model itself when it has none). Each target draws its effect from the enabled ones, by the seed, unless you pin one below.

This page is open through the cloud, so the player's model list cannot be loaded here; the models already chosen are kept. Open the page on the home network to change them.
