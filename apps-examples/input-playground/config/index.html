Input Playground settings

The playground page is a screen of pretend show inputs. Each one makes the HTTP call a controller board would make, POST /api/ezp/inputs/<source>/<name> with {"value": ...}. Map <source>/<name> rows to instance inputs under Show inputs on the Apps card to try them out.

cols is the grid width. Each control has a type (button, switch, slider or text), a name (lower-case letters, digits and dashes, the <name> segment) and a label. Buttons take color, shape (round, square or wide) and mode (press, or press-release to send 1 on the way down and 0 on the way up). Sliders take min, max and step.
